# Your README case study

On card 14 you replace this repo's README with a case study of your own app. It is the first thing anyone sees when they open your repo, so it has to stand alone.

**How to use it:** copy everything below the line into `README.md`, replacing what's there. Fill in every `[bracket]`. Keep the setup steps from the starter's README in a file called `SETUP.md`, so your README is about your app. [`../prompts/write-my-readme.md`](../prompts/write-my-readme.md) does a first draft with you.
